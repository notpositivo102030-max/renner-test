# Checklist final de compliance e LGPD

## Identificação empresarial

- [ ] Razão social validada.
- [ ] CNPJ validado.
- [ ] Endereço validado.
- [ ] E-mails corporativos validados.
- [ ] Telefones oficiais validados.
- [ ] Horário de atendimento definido.
- [ ] Canais oficiais publicados.
- [ ] DPO/encarregado definido e canal LGPD ativo.

## LGPD e privacidade

- [ ] Finalidade da coleta documentada.
- [ ] Base legal validada pelo jurídico.
- [ ] Inventário de dados pessoais e sensíveis atualizado.
- [ ] Política de retenção aprovada.
- [ ] Política de descarte aprovada.
- [ ] Processo de atendimento a direitos do titular definido.
- [ ] Consentimento implementado quando aplicável.
- [ ] Compartilhamentos com operadores/parceiros mapeados.
- [ ] Contratos com operadores revisados.
- [ ] Registro de incidentes e resposta definido.

## Conteúdo institucional

- [ ] Página Sobre a Empresa revisada.
- [ ] Página Segurança revisada.
- [ ] Página Compliance revisada.
- [ ] Política de Privacidade revisada.
- [ ] Termos de Uso revisados.
- [ ] Página LGPD revisada.
- [ ] Página Contato Oficial revisada.
- [ ] Nenhum placeholder `[PREENCHER]` remanescente.
- [ ] Linguagem clara, não ambígua e sem aparência de phishing.

## Evidências e aprovação

- [ ] Aprovação jurídica.
- [ ] Aprovação de segurança da informação.
- [ ] Aprovação de negócio/operação.
- [ ] Aprovação de comunicação/branding.
- [ ] Registro de versão/data dos textos publicados.
